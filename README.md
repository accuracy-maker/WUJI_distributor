# Wuji Research Systems — website demo

A responsive, monochrome static landing page for an Australian distributor serving university and TAFE robotics labs. It uses the product photos embedded in the supplied price-list workbook and brings the Wuji Hand 2 and Wuji Glove to the front, with other listed hand and arm systems in a secondary catalogue section.

The typography follows a clean, geometric sans-serif direction informed by Wuji Technology's product pages. The layout, copy and styling are original.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Before publishing

1. Replace the provisional “Wuji Research Systems” name and footer with your business name and details.
2. In `script.js`, set `ENQUIRY_EMAIL` to an inbox you monitor. The form opens the visitor's email app with the enquiry details filled in. GitHub Pages does not process or store form submissions itself.
3. Confirm product configurations, availability, software access, dataset terms and licensing before making commitments. The visible product specifications come from the supplied product list.
4. Add your business contact details, privacy notice and any manufacturer-approved videos or documents.

Prices are not shown in the demo. The supplied sheet includes channel/distributor pricing and FOB notes that should be reviewed before deciding what belongs on a public site.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to its root (so `index.html` is at the root).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. GitHub will show the public URL when deployment completes. You can connect a custom domain later.

This is a front-end demo only. The form uses `mailto:` and does not store submissions. For a production enquiry form, connect a form service or your own backend and add an appropriate privacy notice.
